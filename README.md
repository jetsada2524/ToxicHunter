# ToxicHunter — เกม (Godot 4.7)

เปิดโปรเจกต์: Import โฟลเดอร์ `ToxicHunter/` ใน Godot แล้วกด **F5**

นักสืบสารพิษ — เลือกสถานที่ → สำรวจห้อง 3D → แตะของที่คิดว่าเป็นสารพิษ →
อ่านการ์ดความรู้ (เก็บที่ไหน/ทิ้งอย่างไร) → หมดเวลาแล้วดูหน้าสรุป

## การควบคุม
- ลากเมาส์ในห้อง = หมุนกล้องดูรอบ ๆ
- แตะของ = ตรวจสอบ (ถูก = สารพิษ +คะแนน · ผิด = ของปลอดภัย −คะแนน)
- ◀ ▶ = สลับห้อง

## ฟีเจอร์บังคับ 4 ข้อ — อยู่ตรงไหน
| # | ฟีเจอร์ | ไฟล์ |
|---|---|---|
| 1 | เลือกสถานที่ + ระดับความยาก | `scripts/level_select.gd`, `data/levels.gd` |
| 2 | ฉากห้อง 3D + วางไอเทมตามตำแหน่ง | `scripts/play.gd`, `scripts/item_prop.gd` |
| 3 | แตะ→อนิเมชันเฉลย+ความรู้+คะแนน | `scripts/reveal_card.gd`, `scripts/game.gd::on_pick` |
| 4 | จับเวลา + หน้าสรุปผล | `scripts/play.gd` (HUD), `scripts/summary.gd` |

## config อ่านผ่าน gdscript (แก้ได้ไม่ต้องแตะโค้ดเกม)
- `data/config.gd` — `RENDER_MODE` ("room3d" / "backdrop2d"), เปิดด่านทั้งหมด, คะแนน, กล้อง
- `data/items.gd` — ฐานข้อมูลสารพิษ + ของปลอดภัย ทุกข้อความที่เด็กอ่านอยู่ที่นี่
  (ครู/ผู้เชี่ยวชาญแก้เนื้อหาได้โดยไม่ต้องเปิด editor)
- `data/levels.gd` — 5 ด่าน (ห้อง เวลา สารพิษ ของปลอดภัย)

## ไอเทม — 3 โหมด เลือกผ่าน config (`ITEM_MODE`)
`item_prop.gd` เลือกวิธีวาดไอเทมตามลำดับ fallback อัตโนมัติ เกมจึงเล่นได้เสมอ:
1. **`"sprite"`** (ค่าเริ่มต้น) — ภาพ AI ตั้งเป็น billboard มีฉลากไทย+สัญลักษณ์ GHS จริง
   เหมาะกับหัวใจเกม "อ่านฉลาก" · ภาพอยู่ที่ `assets/ui/item_<id>.png`
2. **`"model"`** — โมเดล .glb จาก Blender ตินต์สีตามไอเทม (โมเดลเดียวใช้ได้ทุกของเหลว)
3. ทรงพื้นฐาน (primitive) — ถ้าไม่มีทั้งภาพและโมเดล

### เตรียมภาพไอเทม — `tools/prep_items.py`
ภาพที่เจนมามีพื้นชมพูไล่เฉด + เงาใต้ขวด + ลายน้ำ Gemini
สคริปต์ flood-fill จากขอบตามเฉด (ตามเงาได้ด้วย) + ลบลายน้ำมุมขวาล่าง + ครอป + ย่อ + ทำโปร่งใส
ต้นฉบับเก็บที่ `assets/ui/_raw/` รันซ้ำได้เสมอ

### โมเดล 3D — `tools/build_props.py`
รันใน Blender ปั้นไอเทม 6 ทรง (ขวด/สเปรย์/แกลลอน/กล่อง/กระป๋อง/ถุง) export `.glb`

## เสียง
`scripts/sfx.gd` สังเคราะห์ทุกเสียงตอนเปิดเกม ไม่มีไฟล์ .wav (แตะ/เจอ/ผิด/เฉลย/ชนะ/ติ๊กเวลา)

## ยังไม่ได้ทำ (ส่วนขยาย)
- ภาพไอเทมความละเอียดสูงมีฉลากจริง — เขียน prompt ไว้แล้วที่
  `AI_Image_Prompts_ToxicHunter_Items.md` (15 ภาพ) พร้อมทำโหมด billboard sprite ให้เมื่อได้ภาพ
- โหมด backdrop2d (config มีช่องรอไว้แล้ว ยังไม่ได้ต่อ hotspot)
- มินิเกม "เก็บให้ถูกที่", ระบบคำใบ้แบบเสียคะแนน, การ์ดสะสม, ควิซฉุกเฉิน
- ห้อง 3D ปั้นละเอียดใน Blender (ตอนนี้เป็นกล่องเรียบตินต์สี — โครงรองรับสลับได้)
- ให้ผู้เชี่ยวชาญ/ครูวิทย์ตรวจทานเนื้อหาความรู้ก่อนใช้งานจริง
