# รายงานตำแหน่ง item ในฉากค้นหา (game_play_scene)

สร้างเมื่อ 2026-10-19 จากฉากใหม่ใน `assets/ui/game_play_scene/` และ item sheet ใน `assets/ui/items_sheet/` (ไม่ได้แก้ไขไฟล์ทั้งสองชุด)

## สรุป

- หา item จาก item sheet เจอในฉากครบ **146/146** รายการ ใน 19 ฉาก (ไม่มีรายการที่หาไม่เจอ)
- กรอบ (collision area) ของแต่ละ item อยู่ใน `data/painted_rooms.gd` เป็นเปอร์เซ็นต์ของภาพ (x0, y0, x1, y1) เผื่อขอบออกไป 0.3% ให้กดง่ายขึ้น
- ภาพตรวจสอบ: `assets/items_position/<ฉาก>.jpg` กรอบแดง = สารพิษ, กรอบเขียว = ของปลอดภัย พร้อมกล่องชื่อ (ไอคอนจาก item sheet, ชื่อไทย, id)
- ภาพ item ที่ใช้ใน popup ให้ความรู้, กล่อง "ค้นพบแล้ว" และหน้าสรุปผล ตัดมาจาก item sheet ของฉากนั้น ๆ เก็บไว้ที่ `assets/ui/items_icons/<ฉาก>/<id>.png`
- ไฟล์เก่าย้ายไปที่ `assets/backup/` (มี `.gdignore` เพื่อไม่ให้ Godot import ซ้ำ)

## สิ่งที่ควรตรวจ / แก้เพิ่ม

1. เปิด Godot editor ให้ import ไฟล์ใหม่ (`game_play_scene/*.jpeg`, `items_icons/`) แล้วกด Reload ถ้าเปิดไฟล์ `data/painted_rooms.gd`, `data/levels.gd` หรือ `scripts/play.gd` ค้างไว้ (เลือก Don't Save)
2. ฉากที่มี "ของซ้ำ/หน้าตาคล้าย" ตามข้อสังเกตด้านบน: ของชิ้นที่ไม่ได้ตีกรอบจะกดไม่ได้ ผู้เล่นอาจสับสน ถ้าต้องการให้ไม่มี item ซ้ำจริง ๆ ควรแก้ภาพฉากเหล่านั้น (ผมไม่ได้แก้ภาพตามที่สั่ง)
3. item เล็กมากบางชิ้น เช่น ยาฆ่าแมลงบนชั้นบนสุดของห้องอาหาร, จาระบีบนชั้นบนของห้องสินค้า, สีผสมอาหารในห้องวิจัย อาจหายากสำหรับเด็ก ลองเล่นแล้วพิจารณาว่าควรขยายในภาพหรือไม่
4. รายการ safe ใน `data/levels.gd` ตัด id ที่ไม่มีในฉากใหม่ออก: โรงเรียน `chili_sauce`, โรงงาน `detergent_powder`, `laundry_bleach`, `latex_glue`
