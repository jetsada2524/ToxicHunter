# ToxicHunter — เอกสารออกแบบเกม (Game Design Document)

> เกม 3D สไตล์ Pixar ให้เด็กสวมบทเป็น "นักสืบสารพิษ" ค้นหาของอันตรายในบ้าน คอนโด โรงเรียน โรงงาน และฟาร์ม — เลือกถูกได้คะแนน พร้อมเรียนรู้ว่าสารพิษคืออะไร ควรเก็บไว้ที่ไหน และกำจัดอย่างไรให้ปลอดภัย

- **เวอร์ชันเอกสาร:** 0.1 (Concept)
- **วันที่:** 28 ก.ค. 2026
- **Engine:** Godot 4.7 (เกม) + Blender (โมเดล/เรนเดอร์ 3D)
- **สไตล์ภาพ:** 3D Animation, Pixar-style (นุ่ม โค้งมน สดใส ของใช้ในบ้านน่ารัก)
- **กลุ่มเป้าหมาย:** เด็กอายุ 7–12 ปี (เล่นครั้งละ 1 คน เหมาะกับงานนิทรรศการ/ห้องเรียน/แท็บเล็ต)
- **แนวเกม:** Hidden object / Search & Identify + edutainment (ความปลอดภัยจากสารเคมีในชีวิตประจำวัน)

---

## 1. วิสัยทัศน์ (Vision)

ในบ้านของเรามี "สารพิษ" ซ่อนอยู่มากกว่าที่คิด — น้ำยาล้างห้องน้ำใต้อ่าง ยาฆ่าแมลงหลังตู้ ถ่านไฟฉายในลิ้นชัก ToxicHunter เปลี่ยนความรู้เรื่องนี้ให้เป็น **เกมนักสืบสุดสนุก** เด็กได้กวาดสายตาหาของอันตรายในห้อง แตะเพื่อตรวจสอบ แล้วเรียนรู้ทันทีว่าสิ่งนั้นคืออะไร อันตรายอย่างไร **ควรเก็บไว้ที่ไหน** และ **ทิ้งอย่างไรให้ปลอดภัยต่อคนอื่น**

หัวใจของเกมคือ 3 คำ: **มอง (Spot) → ตรวจ (Identify) → เรียนรู้ (Learn)** — เด็กกลับบ้านไปแล้วมองบ้านตัวเองด้วยสายตาใหม่

---

## 2. Core Gameplay Loop

1. **เลือกสถานที่** — เลือกด่าน (คอนโด / บ้าน / โรงเรียน / โรงงาน / ฟาร์ม) ตามระดับความยาก
2. **สำรวจห้อง** — ภาพห้องแบบ 3D สไตล์ Pixar มีข้าวของวางตามตำแหน่งจริง (บางชิ้นเป็นสารพิษ บางชิ้นปลอดภัย)
3. **แตะตรวจสอบ item** — เลือกสิ่งที่คิดว่าเป็นสารพิษ
4. **อนิเมชันเฉลย** — ของชิ้นนั้นลอยขึ้นมา หมุนโชว์ พร้อมการ์ดความรู้:
   - **ถูก (เป็นสารพิษ):** +คะแนน · บอกชื่อสาร · อันตรายอย่างไร · **ควรเก็บที่ไหน** · **กำจัด/ทิ้งอย่างไร**
   - **ผิด (ไม่เป็นสารพิษ):** −คะแนน · บอกว่าคืออะไร ประกอบด้วยอะไร และทำไมถึงปลอดภัย
5. **ทำต่อจนหมดเวลา** — นาฬิกาเดินตลอด ยิ่งเจอเยอะยิ่งได้คะแนน
6. **หน้าสรุป** — แสดงว่าเจอสารพิษอะไรบ้าง (เช็กลิสต์) พลาดอะไรไป และคะแนนรวม

## 3. ฟีเจอร์ที่ต้องมี (Required Features)

### 3.1 เลือกสถานที่ + ระดับความยาก
- หน้าเลือกด่านแสดงการ์ดสถานที่ พร้อมดาวบอกความยาก จำนวนห้อง และจำนวนสารพิษที่ซ่อนอยู่

| ด่าน | ความยาก | ห้อง | สารพิษ | เวลา | ตัวอย่างสารพิษเด่น |
|---|---|---|---|---|---|
| **คอนโด** | ★☆☆☆☆ | 3 (นอน / น้ำ / ครัวเล็ก) | 5 | 2:00 | น้ำยาล้างห้องน้ำ, ถ่านไฟฉาย, น้ำหอมปรับอากาศ |
| **บ้าน** | ★★☆☆☆ | 6 (+ ครัวใหญ่ / โรงรถ / สวน) | 10 | 3:00 | ยาฆ่าแมลง, น้ำมันเครื่อง, ปุ๋ย, ทินเนอร์ |
| **โรงเรียน** | ★★★☆☆ | 5 (ห้องวิทย์ / ศิลปะ / พยาบาล / ทำความสะอาด / โรงอาหาร) | 12 | 3:00 | สารเคมีในแล็บ, สีน้ำมัน, แอลกอฮอล์, น้ำยาฆ่าเชื้อ |
| **โรงงาน** | ★★★★☆ | 5 (ผลิต / เก็บสาร / ซ่อมบำรุง / ห้องแล็บ / โกดัง) | 15 | 4:00 | กรด/ด่างเข้มข้น, ตัวทำละลาย, โลหะหนัก, ถังแก๊ส |
| **ฟาร์ม** | ★★★★★ | 5 (โรงเก็บ / คอกสัตว์ / แปลงผัก / โรงปุ๋ย / บ่อน้ำ) | 15 | 4:00 | ยาฆ่าหญ้า, ยาฆ่าแมลงเกษตร, ยาสัตว์, ปุ๋ยเคมี |

- **ปลดล็อกตามลำดับ:** ผ่านด่านง่ายก่อนถึงเปิดด่านยากขึ้น (หรือเปิดทั้งหมดในโหมดนิทรรศการ)

### 3.2 ฉากสถานที่ + item วางตามตำแหน่ง
- เมื่อเลือกด่าน จะเข้าสู่ **ฉาก 3D ของสถานที่นั้น** มองเห็นห้องและข้าวของวางตามตำแหน่งสมจริง (ใต้อ่าง, บนชั้น, ในตู้, หลังประตู)
- **กล้อง:** มุมมองห้องแบบ 3/4 หมุน/แพนได้ · เปลี่ยนห้องด้วยปุ่มลูกศรหรือแตะประตู
- **ของบางชิ้นซ่อนบางส่วน** (ต้องเปิดตู้/ยกผ้า) เพิ่มความท้าทายในด่านยาก
- ผสม **ของอันตราย** กับ **ของปลอดภัย** ที่หน้าตาคล้ายกัน เช่น ขวดน้ำยาล้างจาน (ปลอดภัย) vs ขวดน้ำยาล้างห้องน้ำ (อันตราย) — บังคับให้เด็กสังเกตฉลาก

### 3.3 แตะ item → อนิเมชันเฉลย + ให้ความรู้ + คะแนน
เมื่อผู้เล่นแตะ item ของชิ้นนั้นจะ **ลอยขึ้นกลางจอ หมุนโชว์ 360°** พร้อมการ์ดความรู้:

**กรณีถูก — เป็นสารพิษ ✅ (+คะแนน)**
- **นี่คืออะไร:** ชื่อสาร/ผลิตภัณฑ์ + สารเคมีหลักที่อยู่ในนั้น
- **อันตรายอย่างไร:** เช่น กัดผิวหนัง ระคายเคืองตา ไอระเหยเป็นพิษ กินแล้วอันตราย
- **ควรเก็บไว้ที่ไหน:** เช่น ตู้สูงมีล็อก พ้นมือเด็ก แยกจากอาหาร ที่อากาศถ่ายเท
- **กำจัด/ทิ้งอย่างไร:** เช่น ห้ามเทลงท่อ/ชักโครก · ปิดฝาให้แน่นทิ้งถังขยะอันตราย (ถังแดง) · ถ่านไฟฉายทิ้งจุดรับขยะอิเล็กทรอนิกส์
- มีสัญลักษณ์ GHS (หัวกะโหลก/ระคายเคือง/ไวไฟ) แสดงประกอบให้เด็กจำได้

**กรณีผิด — ไม่เป็นสารพิษ ❌ (−คะแนน)**
- **นี่คืออะไร:** ชื่อของ + ประกอบด้วยอะไร (เช่น สบู่ = ไขมัน + ด่างอ่อน ผ่านการทำปฏิกิริยาแล้ว)
- **ทำไมถึงปลอดภัย:** อธิบายเหตุผลสั้นๆ ไม่ตำหนิเด็ก ("เกือบไปแล้ว! ของชิ้นนี้ปลอดภัยนะ เพราะ...")
- ยังคงให้ความรู้ ไม่ทำให้รู้สึกแย่ — แค่เสียคะแนนเล็กน้อย

### 3.4 จับเวลา + หน้าสรุปผล
- **นาฬิกานับถอยหลัง** ตามด่าน (2:00–4:00) แสดงมุมบนของจอ · 15 วินาทีสุดท้ายเร้าใจ
- เมื่อหมดเวลา (หรือเก็บครบ) แสดง **หน้าสรุป**:
  - **เช็กลิสต์สารพิษ** ในด่านนั้น: เจอแล้ว ✅ / ยังไม่เจอ ⬜ (พร้อมเฉลยตำแหน่ง)
  - **คะแนนรวม** แยกเป็น: ได้จากสารพิษที่เจอ − หักจากที่เลือกผิด + โบนัสเวลา
  - **สรุปความรู้:** การ์ดสรุปสั้นๆ ของสารที่เจอในรอบนั้น
  - **ระดับผลงาน:** เช่น นักสืบฝึกหัด / นักสืบมือดี / ยอดนักสืบสารพิษ
  - ปุ่ม เล่นซ้ำ / เลือกด่านใหม่

## 4. ไอเดียเสริม เพื่อความตื่นเต้น + ความรู้ (Edutainment Layer)

ส่วนนี้คือข้อเสนอเพิ่มเติมของผม เพื่อให้เด็ก "อยากเล่นซ้ำ" และ "ได้ความรู้ติดตัว":

**ตัวนำทางน่ารัก (Mascot).** น้อง **"หมาน้อยจมูกไว (Detective Nose)"** สุนัขนักสืบใส่แว่นขยาย คอยพากย์ ให้คำใบ้ และเล่าเกร็ดความรู้ ("ได้กลิ่นแปลกๆ จากใต้อ่างล้างจานนะ ลองไปดูสิ!")

**แว่นขยายตรวจสอบ (Inspect Mode).** แตะค้างเพื่อซูมดูฉลากของจริง — เด็กได้ฝึก **อ่านฉลากและสัญลักษณ์เตือน** ซึ่งเป็นทักษะใช้ได้จริงในชีวิต

**ระบบคำใบ้ (Hint).** ถ้าติดนาน มาสคอตจะบอกใบ้แบบไม่เฉลยตรงๆ ("ห้องน้ำยังมีของอันตรายอีก 1 ชิ้นนะ") — ใช้คำใบ้แล้วได้คะแนนน้อยลงนิดหน่อย

**คอมโบนักสืบ (Detective Streak).** เลือกถูกติดต่อกันได้ตัวคูณคะแนน เร้าใจและกระตุ้นให้คิดก่อนแตะ

**ภารกิจเก็บให้ถูกที่ (Sort It Right) — มินิเกมท้ายด่าน.** ลากสารพิษที่เจอไปใส่ให้ถูก: **ตู้ล็อกพ้นมือเด็ก / ถังขยะอันตราย / จุดรับขยะอิเล็กทรอนิกส์ / ห้ามเทลงท่อ** — ตอกย้ำความรู้เรื่องการเก็บและกำจัด (ข้อ 3.3) ด้วยการลงมือทำ

**การ์ดสะสมความรู้ (Toxic Card Collection).** เจอสารชนิดใหม่ = ปลดล็อกการ์ดข้อมูลเก็บไว้ในสมุด (สำหรับโหมดเล่นที่บ้าน/โรงเรียน — โหมดนิทรรศการปิดได้)

**สถานการณ์ฉุกเฉิน (Emergency Quiz).** สุ่มถามสั้นๆ ระหว่างด่าน เช่น "ถ้าน้องเผลอกินน้ำยาล้างห้องน้ำ ควรทำอย่างไร?" → สอน **ห้ามทำให้อาเจียน + รีบโทร 1669** ความรู้ช่วยชีวิตจริง

**ความจริงน่าตกใจ (Did You Know).** เกร็ดจริงระหว่างโหลด เช่น "น้ำยาล้างห้องน้ำผสมกับน้ำยาฟอกขาว = แก๊สพิษ ห้ามผสมเด็ดขาด!"

**เสียงและฟีล (Juice).** เสียง "ติ๊ง!" ตอนเจอ · ของเรืองแสงตอนเมาส์ผ่าน · มาสคอตเต้นตอนเลือกถูก · จอสั่นเบาๆ ตอนเลือกผิด

**โหมดเสริม (ถ้ามีเวลา):** โหมดสำรวจไม่จับเวลา (เรียนรู้อย่างเดียว), โหมดแข่งกับเวลาส่วนตัว (Time Attack), ตารางคะแนนของงานนิทรรศการ

## 5. ฐานข้อมูลสารพิษ (ตัวอย่าง — Toxic Item Database)

| ไอเทม | สารเคมีหลัก | อันตราย | ควรเก็บที่ไหน | กำจัดอย่างไร |
|---|---|---|---|---|
| น้ำยาล้างห้องน้ำ | กรดไฮโดรคลอริก | กัดผิวหนัง/ตา ไอระเหยแสบ | ตู้ล็อกในห้องน้ำ พ้นมือเด็ก | ใช้ให้หมด ล้างขวดแล้วทิ้งถังขยะอันตราย · **ห้ามผสมน้ำยาฟอกขาว** |
| น้ำยาฟอกขาว | โซเดียมไฮโปคลอไรต์ | ระคายเคือง ผสมสารอื่นเกิดแก๊สพิษ | ที่มืด เย็น อากาศถ่ายเท | เจือจางน้ำมากๆ ก่อนทิ้ง · ห้ามผสมกรด |
| ยาฆ่าแมลง (สเปรย์) | ไพรีทรอยด์ | พิษต่อระบบประสาท ไวไฟ | ตู้สูงมีล็อก แยกจากอาหาร | กระป๋องเปล่าทิ้งขยะอันตราย · ห้ามเผา/เจาะ |
| ถ่านไฟฉาย / แบตเตอรี่ | สังกะสี แมงกานีส ลิเทียม | สารรั่วกัดผิว โลหะหนักปนเปื้อน | กล่องแห้ง แยกจากของเล่น | **จุดรับขยะอิเล็กทรอนิกส์** · ห้ามทิ้งขยะทั่วไป |
| ทินเนอร์ / น้ำมันสน | โทลูอีน | ไอระเหยทำลายสมอง ไวไฟมาก | โรงรถ อากาศถ่ายเท ห่างประกายไฟ | ส่งจุดรับของเสียอันตราย · **ห้ามเทลงท่อ** |
| ปุ๋ยเคมี / ยาฆ่าหญ้า | ไนเตรต ไกลโฟเซต | พิษถ้ากิน ปนเปื้อนแหล่งน้ำ | โรงเก็บมีล็อก ห่างบ่อน้ำ | ตามคำแนะนำฉลาก · ห้ามล้างลงคลอง |
| น้ำยาล้างจาน *(ปลอดภัย)* | สารลดแรงตึงผิวอ่อน | ระคายเคืองเล็กน้อยถ้าเข้าตา | ใต้อ่างล้างจานทั่วไป | ล้างน้ำได้ตามปกติ |
| สบู่ / ยาสีฟัน *(ปลอดภัย)* | ไขมัน+ด่างอ่อน / ฟลูออไรด์ | ปลอดภัยเมื่อใช้ตามปกติ | ชั้นวางในห้องน้ำ | ทิ้งขยะทั่วไป |

> **หมายเหตุ:** เนื้อหาความรู้ทั้งหมดควรให้ผู้เชี่ยวชาญ/ครูวิทยาศาสตร์ตรวจทานก่อนใช้งานจริง และปรับภาษาให้เหมาะกับวัย

## 6. หน้าจอและ Flow (UX Flow)

```

      → [ฉากห้อง 3D + จับเวลา]
            ↳ แตะ item → [อนิเมชันเฉลย + การ์ดความรู้] → +/− คะแนน → กลับสู่ห้อง
            ↳ เปลี่ยนห้องได้ตลอด
      → [หมดเวลา] → [มินิเกม: เก็บให้ถูกที่] → [หน้าสรุปผล + เช็กลิสต์ + คะแนน]

```

## 7. สถาปัตยกรรมทางเทคนิค (Godot 4.7)

### 7.1 โครงสร้างฉาก (Scenes)
- `Main.tscn` — จัดการสถานะเกม (เมนู → เลือกด่าน → เล่น → สรุปผล)
- `LevelSelect.tscn` — การ์ดเลือกสถานที่ + ระดับความยาก
- `Location.tscn` — ฉากสถานที่ (มีหลาย `Room` ย่อย)
- `Room.tscn` — ห้อง 1 ห้อง + จุดวาง item (`Marker3D`)
- `InspectableItem.tscn` — ของ 1 ชิ้น (ข้อมูล, โมเดล, highlight, พื้นที่คลิก)
- `RevealCard.tscn` — อนิเมชันเฉลย + การ์ดความรู้
- `SummaryScreen.tscn` — เช็กลิสต์ + คะแนน + ระดับผลงาน
- `HUD.tscn` — นาฬิกา + คะแนน + ตัวนับ "เจอแล้ว x/y" + มาสคอต

### 7.2 โมเดลข้อมูลไอเทม (ItemData resource)
```gdscript
class_name ItemData extends Resource
@export var display_name: String        # ชื่อที่แสดง
@export var is_toxic: bool              # เป็นสารพิษหรือไม่
@export var chemical: String            # สารเคมีหลัก / ส่วนประกอบ
@export var danger_text: String         # อันตรายอย่างไร (ถ้า toxic)
@export var store_where: String         # ควรเก็บที่ไหน
@export var dispose_how: String         # กำจัด/ทิ้งอย่างไร
@export var safe_reason: String         # ทำไมปลอดภัย (ถ้าไม่ toxic)
@export var ghs_icons: Array[Texture2D] # สัญลักษณ์เตือน
@export var points: int = 100           # คะแนนเมื่อเลือกถูก
@export var penalty: int = -50          # คะแนนเมื่อเลือกผิด
@export var model: PackedScene
```
> ใช้ Resource `.tres` แยกไฟล์ต่อไอเทม — ครู/ผู้เชี่ยวชาญแก้เนื้อหาได้โดยไม่ต้องแตะโค้ด

### 7.3 การเลือกและเฉลย (3.3)
```gdscript
func on_item_selected(item: InspectableItem) -> void:
    if item.inspected: return
    item.inspected = true
    var d := item.data
    if d.is_toxic:
        score += d.points
        found_toxic.append(d)
        RevealCard.show_correct(d)     # ชื่อ + อันตราย + เก็บที่ไหน + ทิ้งอย่างไร
    else:
        score += d.penalty             # ติดลบ
        RevealCard.show_wrong(d)       # คืออะไร + ประกอบด้วยอะไร + ทำไมปลอดภัย
    item.play_float_and_spin()         # ลอยขึ้น หมุนโชว์ 360°
```

### 7.4 การวาง item ในห้อง (3.2)
- แต่ละห้องมี `Marker3D` เป็นจุดวางที่ออกแบบไว้ (ใต้อ่าง บนชั้น ในตู้)
- ตอนเริ่มด่าน **สุ่มเลือกชุด item** จากพูล (toxic + safe) วางลงจุดต่างๆ → เล่นซ้ำได้ไม่เบื่อ
- ของที่ซ่อน: ตั้ง flag `requires_open` (ต้องเปิดตู้/ยกของก่อน)

### 7.5 จับเวลา + สรุปผล (3.4)
- `Timer` ตามด่าน · หมดเวลา → รวบรวม `found_toxic` เทียบกับ `all_toxic_in_level` → แสดงเช็กลิสต์ + คะแนน + โบนัสเวลา

### 7.6 อาร์ตและโมเดล
- โมเดลห้องและ props สไตล์ Pixar ปั้นใน **Blender** → export `.glb` เข้า Godot
- ใช้ material นุ่มมัน (soft glossy) + แสงอบอุ่น · ของอันตรายมี **ขอบเรืองแสงบางๆ ตอนชี้** (ไม่บอกใบ้ว่าอันตรายหรือไม่)

## 8. ทิศทางศิลป์ (Art Direction — Pixar Style)

- **ห้องอบอุ่นน่าอยู่:** ไม่ใช่บ้านน่ากลัว — แสงแดดลอดหน้าต่าง สีพาสเทลสดใส เฟอร์นิเจอร์มนโค้ง
- **ของใช้มีบุคลิก:** ขวดน้ำยา กระป๋องสเปรย์ ออกแบบให้ดูน่ารักแต่ยังจำได้ว่าคือของจริงชนิดไหน
- **สัญลักษณ์อันตรายชัดเจน:** ใช้ไอคอน GHS จริง (หัวกะโหลก ไวไฟ กัดกร่อน) เพื่อให้เด็กจดจำของจริงได้
- **มาสคอต:** หมาน้อยนักสืบ ตาโต ใส่แว่นขยาย เคลื่อนไหว bouncy
- **UI:** ปุ่มใหญ่ มุมมน อ่านง่าย · การ์ดความรู้พื้นหลังโปร่งนุ่ม อ่านสบายตา
- **สร้างงานต้นฉบับเอง ไม่ลอกผลงานผู้อื่น**

## 9. ขอบเขต MVP vs. ส่วนขยาย

**MVP (ต้องมีให้ครบ):** เลือกสถานที่ + ระดับความยาก · ฉากห้อง 3D มี item วางตามตำแหน่ง · แตะ item → อนิเมชันเฉลย + ความรู้ (ถูก: ชื่อ/เก็บที่ไหน/ทิ้งอย่างไร + คะแนน · ผิด: คืออะไร/ประกอบด้วยอะไร + ติดลบ) · จับเวลา + หน้าสรุปผล

**ส่วนขยาย (ถ้ามีเวลา):** มาสคอตหมานักสืบ, แว่นขยายอ่านฉลาก, ระบบคำใบ้, คอมโบ, มินิเกม "เก็บให้ถูกที่", การ์ดสะสม, ควิซฉุกเฉิน, Did You Know, โหมดสำรวจ/Time Attack

> บริบทการใช้งาน: เล่นครั้งละ 1 คน — เหมาะทั้งงานนิทรรศการ (ด่านสั้น 2 นาที) และห้องเรียน (ด่านยาว + โหมดสำรวจ)
