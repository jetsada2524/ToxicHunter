# รายงานไอคอน item: ภาพในฉาก vs item sheet

อัปเดต 15 ต.ค. 2026

เกมใช้รูปจาก **item sheet ของแต่ละด่าน** (`assets/ui/<ด่าน>_items/<id>.png`) เป็นหลัก ใช้กับป๊อปอัปตอนกดเลือก แถบ "ค้นพบ" และหน้าสรุปผล
item ที่ยังไม่มีไอคอนใน sheet เกมจะใช้รูปที่ตัดจากฉาก (`assets/ui/room_items/`) แทนไปก่อน
พอเพิ่มไอคอนลงโฟลเดอร์ sheet โดยตั้งชื่อเป็น `<id>.png` เกมจะเปลี่ยนไปใช้ไอคอนนั้นเองทันที

**ความหมายของเครื่องหมาย**
- **🔴** = สารพิษ (ของที่ต้องหา)
- **🔵** = item หลอก
- **#** = ลำดับจุดคลิกใน `data/painted_rooms.gd` ของห้องนั้น

## 2. มีไอคอนแล้ว แต่หน้าตาไม่ตรงกับของในฉาก

### ต่างมาก (ควรแก้ก่อน)

| ด่าน / ห้อง | item | ของในฉาก | ไอคอนใน sheet |
|---|---|---|---|
| ฟาร์ม / โรงเก็บวัสดุ #0 | 🔴 ยาฆ่าแมลง (`bug_spray`) | แกลลอนสีส้ม มีรูปหัวกะโหลก | กระป๋องสเปรย์ |
| ฟาร์ม / โรงเรือนเลี้ยงสัตว์ #0 | 🔴 ยาเบื่อหนู (`rat_poison`) | ขวดสีน้ำตาล มีรูปหัวกะโหลก | กล่องกระดาษ "ยาเบื่อหนู" |
| ฟาร์ม / โรงเรือนกระจก #1 | 🔵 ปุ๋ยเคมี (`chemical_fertilizer`) | แกลลอนสีเขียว ฉลากรูปหยดน้ำ | ถุงปุ๋ย "ปุ๋ยเคมี" (ส่วนในโรงเก็บวัสดุเป็นถุงตรงกับ sheet) |
| ฟาร์ม / โรงเรือนกระจก #7 | 🔵 ฮอร์โมนพืช (`plant_hormone`) | ขวดสีขาว ฝาเขียว | แกลลอนสีเขียว (ส่วนในโรงเก็บวัสดุตรงกับ sheet) |
| ฟาร์ม / โรงเก็บวัสดุ #7 | 🔵 น้ำยาล้างจาน (`dish_soap`) | แกลลอนสีขาว ฉลากว่าง | ขวดสีเหลือง |
| ฟาร์ม / โรงเรือนเลี้ยงสัตว์ #2 | 🔵 ยากำจัดเห็บหมัด (`fungicide`) | ขวดสีน้ำตาล ฉลากเขียนผิด | ขวดหยดสีน้ำตาล |

| บ้าน / ห้องครัว #0 | 🔴 น้ำยากำจัดปลวก (`termite_killer`) | กระป๋องทรงสูง | ถังมีหูหิ้ว |
| คอนโด / ห้องนั่งเล่น #3 | 🔵 น้ำยาล้างจาน (`dish_soap`) | ขวดเหลือง + ขวดส้ม 2 ขวด | ขวดเหลืองขวดเดียว |
| คอนโด / ห้องนั่งเล่น #8, ห้องน้ำ #9 | 🔵 น้ำยาซักผ้า (`laundry_detergent`) | ถุงเติมสีม่วง (ห้องนั่งเล่น) | ถุงเติมสีฟ้า |
| โรงงาน / ห้องเก็บพัสดุ #0 | 🔴 โซเดียมไซยาไนด์ (`sodium_cyanide`) | ถังเหล็ก 2 ใบ ฉลากชื่อ | ถังเหล็กใบเดียว มีรูปหัวกะโหลก |
| โรงงาน / ห้องวิจัย #1 | 🔵 สีผสมอาหาร (`food_coloring`) | ขวดเล็กหลายขวดบนชั้น | ขวดเดียว "สีผสมอาหาร" |
| โรงเรียน / ห้องวิทยาศาสตร์ #3 | 🔵 สีผสมอาหาร (`food_coloring`) | ขวดเล็กเรียงเป็นแถว | ขวดเดียว |

ควรเลือกให้ชื่อ ไอคอน และฉลากในฉากไปทางเดียวกัน

### ไอคอนใน sheet ไม่มีฉลาก แต่ของในฉากมี (ไม่ต้องแก้ก็ได้)
- **ทั้งห้อง:** คอนโด / ห้องนั่งเล่น และห้องน้ำ
- **บางชิ้น:**
  - โรงเรียน: สีสเปรย์ ผงเบกกิ้งโซดา (ห้องอาหาร) ซอสปรุงรส (ห้องวิทยาศาสตร์ และห้องอาหาร)
  - ฟาร์ม: ยาฆ่าเชื้อในคอกสัตว์

## 3. สิ่งที่แก้ไปแล้วในรอบนี้
- **โรงงาน / ห้องวิจัย:** ตอนนี้ฉลากเขียน "เอทานอลล้างแผล" แล้ว ตรงกับ sheet สบู่เหลวล้างมือเหลือแค่รอไอคอนใน sheet (`hand_soap`)
- **ฟาร์ม / โรงซ่อมบำรุง:** กระป๋องสีม่วงบนพื้นเป็นฉลากว่างแล้ว ผมไม่ได้ทำเป็นจุดคลิก จึงเป็นแค่ของตกแต่ง
- **โรงเรียน / ห้องพยาบาล:** ขวดฉลาก "แอลกอฮอล์ 70%" ตั้งเป็นแอลกอฮอล์ตามที่ตกลงกันไว้
